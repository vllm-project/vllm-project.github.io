Notes and assumptions

MSA cuts what each query reads (2,048 keys per layer), not what the cache stores: every token’s K and V stay resident.

TP splits K/V by head; index K has one head, so every TP rank keeps a full copy. Index K uses the KV dtype. NVFP4 = 4-bit values + one FP8 scale per 16 (4.5 bits).

Weights = safetensors total_size, 250.1 GB (routed experts NVFP4 ≈ 232 GB, rest ≈ 18 GB). Routed experts split by TP/EP; under DEP the rest sits on every GPU. 95% of HBM usable. 1 GB = 10⁹ B.
