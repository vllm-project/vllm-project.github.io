One duplex session framework, two execution modes

The interface carries the conversation. The execution mode determines how the model processes continuing input. Streaming a response is possible in every path shown here; native duplex additionally incorporates continuing input into ongoing model computation.

Realtime / Duplex uses OpenAI Realtime event conventions with vLLM-Omni extensions. Video, playback feedback, and session resume depend on the model.

Realtime also has a separate turn-mode service at /v1/realtime?duplex=0, outside the unified duplex paths shown here.
